# Real-Time Object Detection using YOLO11

A real-time object detection system built using **YOLO11** and **OpenCV** that detects and localizes objects from live camera streams and video files.

The project demonstrates the complete computer vision inference pipeline, including model loading, real-time detection, bounding box visualization, confidence filtering, and video processing.

---

# Project Overview

Object detection is one of the fundamental tasks in computer vision, where the goal is to identify and locate multiple objects inside an image or video.

This project implements a real-time object detection system capable of detecting objects from:

- Webcam input
- Custom video files
- Real-world scenes

The system uses the YOLO11 object detection model because of its balance between accuracy and inference speed.

---

# Features

## Real-Time Detection

- Live camera object detection
- Video file inference
- Frame-by-frame processing
- Real-time bounding box visualization

---

## Object Localization

The model provides:

- Object class labels
- Bounding boxes
- Confidence scores
