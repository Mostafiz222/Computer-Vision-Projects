# Coin Counter using Computer Vision

A computer vision-based coin counting system that detects and counts coins from images using image processing techniques.

The project demonstrates a complete classical computer vision pipeline including image preprocessing, segmentation, contour detection, object localization, and automated counting.

---

# Project Overview

Manual coin counting can be time-consuming and error-prone. This project automates the process by analyzing an input image and identifying individual coins using computer vision techniques.

The system can:

- Detect coins from images
- Separate coins from the background
- Count the number of coins automatically
- Visualize detected coin regions

---

# Features

## Automatic Coin Detection

The system detects coins using:

- Image preprocessing
- Thresholding
- Edge detection
- Contour extraction

---

## Image Processing Pipeline

The pipeline includes:

1. Image loading
2. Grayscale conversion
3. Noise reduction
4. Image thresholding
5. Morphological operations
6. Contour detection
7. Coin counting

---

## Visualization

The output displays:

- Detected coin boundaries
- Coin count
- Processed image results
