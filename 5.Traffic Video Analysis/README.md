# Real-Time Traffic Detection and Vehicle Analytics using YOLO11

A computer vision-based traffic monitoring system that detects, tracks, and analyzes vehicles from traffic videos in real time. The project uses **YOLO11 for object detection** and **ByteTrack for multi-object tracking** to perform vehicle counting and traffic analytics.

The system can:

- Detect vehicles from video streams
- Track individual vehicles across frames
- Count vehicles crossing a virtual line
- Identify vehicle categories
- Display live traffic statistics
- Generate an annotated output video
